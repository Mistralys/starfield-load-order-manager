## Overview

The application requires specific configuration settings to function properly. This document covers required settings, validation, and auto-discovery features.

## Required Settings

The application requires two essential configuration settings:

1. **Starfield AppData Path**: Where `Plugins.txt` is located
2. **Starfield Game Path**: Where the `Data` folder with mods is located

---

## Optional Settings

3. **Active Profile ID**: Currently selected profile (default: "default")

---

## Configuration Validation

The application validates configuration on startup and continuously during runtime.

### Validation Checks

- Paths are not empty
- Directories exist on disk
- Game `Data` folder exists
- **Plugins.txt file exists** (required, cannot be auto-generated by application)
- **Profiles folder can be created and is writable** (tested with temporary file)
- Continuous validation during runtime via timer ticks
- Real-time feedback in settings window

### Validation Order

**Sequential validation**: paths configured ? paths exist ? Data folder exists ? Plugins.txt exists ? Profiles folder writable

Each check depends on the previous ones being successful for efficiency.

## Auto-Discovery

Common installation paths are checked and pre-filled when found.

### Detected Paths

**Steam** (primary):
- Auto-detected using Steam library folders
- Searches all configured Steam libraries
- See [Steam Library Detection](#steam-library-detection) below

**AppData**:
- `%LOCALAPPDATA%\Starfield`
- Standard Windows location for game data

**Shown as clickable links** in settings window for easy application.

> **NOTE**: Installations vary between gaming platforms (Steam, GOG, Microsoft Store, etc.), so auto-discovery may not always work. Users can manually browse to the correct folders using the "Browse..." buttons.

## Steam Library Detection

The application includes intelligent Steam library detection to locate Starfield installations.

### How It Works

1. Detects the main Steam installation path from Windows registry
2. Reads Steam's `libraryfolders.vdf` configuration file
3. Searches all configured Steam library folders for Starfield (AppID: `1716740`)
4. Returns the first valid installation found

### Benefits

- Automatically finds Starfield even when installed in non-default Steam libraries
- No manual configuration needed for most Steam users
- Handles multiple Steam library folders seamlessly
- Validates installation by checking for the `Data` folder

### Fallback Behavior

- If library detection fails, checks default Steam installation location
- Falls back to default Program Files location if needed
- Silent failure ensures no disruption to user experience

### Technical Details

**VDF Parsing**:
- Uses Valve Data Format (VDF) parser (Gameloop.Vdf library)
- Parses numeric library keys (0, 1, 2, ...) from `libraryfolders.vdf`
- Checks each library's `apps` property for Starfield's AppID
- Constructs path: `{library-path}/steamapps/common/Starfield`

**Path Normalization**:
- Converts forward slashes to backslashes
- Validates installation completeness before returning path
- Checks for `Data` folder existence

**Registry Keys**:
- `HKEY_CURRENT_USER\Software\Valve\Steam` (primary)
- `HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Valve\Steam` (fallback)

This feature significantly improves the first-run experience for Steam users who have Starfield installed in custom library locations.

## Configuration File

### Storage Location

`%LOCALAPPDATA%/StarfieldLoadOrderKeeper/appsettings.json`

### File Format

```json
{
  "appDataPath": "C:\\Users\\Username\\AppData\\Local\\Starfield",
  "gamePath": "C:\\Program Files (x86)\\Steam\\steamapps\\common\\Starfield",
  "activeProfileId": "my-character"
}
```

### Properties

**`appDataPath`** (string, required):
- Path to Starfield's AppData folder
- Contains `Plugins.txt` file
- Example: `C:\Users\Username\AppData\Local\Starfield`

**`gamePath`** (string, required):
- Path to Starfield installation
- Contains `Data` folder with mod files
- Example: `C:\Program Files (x86)\Steam\steamapps\common\Starfield`

**`activeProfileId`** (string, optional):
- ID of currently active profile
- Defaults to "default" if not specified
- Must match an existing profile folder

## First-Time Setup

### Auto-Detection Attempt

1. Application launches for first time
2. Attempts to detect Steam installation
3. Searches for Starfield in Steam libraries
4. Detects AppData path
5. Pre-fills detected paths in settings window

### Manual Configuration

If auto-detection fails or paths incorrect:

1. Settings window opens automatically on first launch
2. User can browse to correct folders using "Browse..." buttons
3. Real-time validation provides immediate feedback
4. User saves once paths valid

### First-Time Validation

For users who have never run Starfield:

**Expected Behavior**:
1. User installs and launches application
2. Paths auto-detected (if possible)
3. Validation fails: "Plugins.txt not found"
4. Clear error message in settings window
5. User instructed to run Starfield first
6. After running Starfield once, file created
7. Validation passes, application fully functional

**Why This Is Correct**:
- Application genuinely cannot function without Plugins.txt
- Clear guidance prevents user confusion
- Prevents partial functionality and obscure errors
- Ensures proper setup before first use

## Configuration Migration

### Legacy to Profile System

When migrating from pre-profile version:

1. Legacy `Plugins.reference.txt` detected in AppData root
2. Automatically moved to `Profiles/default/reference.txt`
3. Current `Plugins.txt` copied to `Profiles/default/main.txt`
4. Legacy file deleted after successful migration
5. User notified of migration

### Profile Folder Creation

If Profiles folder doesn't exist:

1. Attempted on application startup
2. If creation fails, error dialog shown
3. User can choose to open settings or exit application
4. Settings window guides user to fix path or permissions

## Troubleshooting

### Common Issues

**"Plugins.txt not found"**:
- Run Starfield at least once to create the file
- Verify AppData path is correct
- Check if using Microsoft Store version (different path)

**"Access denied when creating the Profiles folder"**:
- Check folder permissions
- Try running application as administrator
- Select different AppData path with write access

**"The game Data folder was not found"**:
- Verify game path points to Starfield installation root
- Check for `Data` subfolder in game path
- Reinstall game if folder genuinely missing

**Auto-detection fails**:
- Manually browse to correct folders
- Common Steam paths:
  - `C:\Program Files (x86)\Steam\steamapps\common\Starfield`
  - `D:\SteamLibrary\steamapps\common\Starfield`
- Common AppData path:
  - `C:\Users\[Username]\AppData\Local\Starfield`

---

## Best Practices

1. **Run Starfield first** before installing the application
2. **Use auto-detected paths** when possible (most reliable)
3. **Verify paths** point to correct Starfield installation
4. **Check permissions** if Profiles folder creation fails
5. **Keep backups** of important profiles manually if desired
